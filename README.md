# Kaala Mithra — Sales Management webpage

This folder contains a responsive Sales Management services webpage and its editable source project.

## Open the webpage

Open `index.html` in a modern browser. The built page is self-contained; its CSS, fonts, logo and images are embedded.

## Included files

- `index.html` — ready-to-view standalone webpage
- `index.src.html` — editable HTML source
- `theme.css` and `fonts.css` — styling and embedded fonts
- `assets/` — brand logo and original illustrative sales visuals
- `build.py` — rebuilds the standalone webpage
- `qa.py` — static acceptance checks

## Rebuild and check

From this directory, run:

```bash
python3 build.py
python3 qa.py
```

The build script uses Pillow (`PIL`). Install it with `python3 -m pip install Pillow` if needed.
